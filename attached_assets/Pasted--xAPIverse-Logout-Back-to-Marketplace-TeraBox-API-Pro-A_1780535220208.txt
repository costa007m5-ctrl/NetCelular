API Overview
The TeraBox API provides a powerful and programmatic way to interact with TeraBox file links. Whether you're building a video streaming app, a file downloader, or a metadata scraper, this API delivers the data you need in a clean JSON format.

Key Features:
Fast Download Link: Get fast download links for maximum speed.
Multiple Streaming Options: HLS fast streams up to 4K (360p, 480p, 720p, 1080p, 4K) and standard MP4 streaming.
Multi-language Subtitles: M3U8 format subtitle files with support for multiple languages.
Complete Metadata: File size, duration, quality, type, and thumbnail extraction.
Video Quality Detection: Automatic detection of video resolution up to 4K.
Unlimited Bandwidth: No extra cost for streaming or downloading - unlimited bandwidth included with every request.
